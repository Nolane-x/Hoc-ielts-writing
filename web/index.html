Workspace tools

Agent trực tiếp đọc cấu trúc bài viết, định vị bằng chứng nguyên văn, tạo bản vá (Diff Patches) có thể duyệt 1-click, dựng dàn ý và thiết kế bài luyện. Mọi thay đổi đều chờ bạn phê duyệt; bản gốc tuyệt đối an toàn.

NHIỆM VỤ TÁC CHIẾN NHANH (1-CLICK MISSION)
Sẵn sàng. Bạn có thể tiếp tục sửa bài trong lúc Agent phân tích.

    Khi quyền gửi provider được bật, phiên Writing Agent gửi đề hiện tại, bản nháp hiện tại, ghi chú riêng của đề hiện tại và bản tóm tắt tiến trình (điểm tiêu chí/lỗi lặp lại; không gửi nguyên văn bài cũ). Chế độ chủ động chỉ tự gửi sau khi bạn bật công tắc riêng, tạm dừng gõ và vượt ngưỡng nội dung thay đổi; có khoảng nghỉ giữa các lần gọi. Tắt quyền provider sẽ yêu cầu dừng lượt tự động đang chạy. Agent không có shell, quyền đọc file tùy ý, chụp màn hình, microphone hay quyền truy cập API key; công cụ chỉ thao tác trên bài viết và tài liệu học được cung cấp.

    01 / AI CONNECTION ENGINE

    Kết nối AI Provider

    Tích hợp trực tiếp OpenAI, Anthropic, Google Gemini, OpenRouter hoặc mô hình chạy cục bộ (Ollama / LM Studio). WMR yêu cầu khai báo giá minh bạch, không tự ý đoán cước.

    Endpoint từ xa bắt buộc giao thức mã hóa HTTPS. Tuyệt đối không chèn API key vào chuỗi URL.
    Desktop: Khóa chỉ nằm trong bộ nhớ RAM tiến trình, tự xóa khi đóng ứng dụng. Android: Mã hóa phần cứng trong Android Keystore.

    Sao lưu & Khôi phục dữ liệu

    Toàn quyền kiểm soát và di chuyển dữ liệu học tập giữa các thiết bị thông qua định dạng chuẩn JSON.

    Xuất toàn bộ hồ sơ học tập Tải xuống file JSON chứa toàn bộ bản nháp, lịch sử báo cáo, tài liệu Agent và nhật ký bài luyện.
    Khôi phục từ bản sao lưu Nhập file JSON đã sao lưu. Khóa bảo mật API key và công tắc quyền riêng tư không bị ghi đè.
